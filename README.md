# 🤖 ربات جستجوی پروژه گیت‌هاب با هوش مصنوعی

ربات تلگرامی هوشمند برای پیدا کردن پروژه‌های گیت‌هاب با استفاده از OpenAI و GitHub API

## ✨ امکانات

- تبدیل درخواست فارسی/انگلیسی به کوئری بهینه گیت‌هاب با هوش مصنوعی
- نمایش اطلاعات کامل پروژه شامل نام، توضیحات، ستاره‌ها، زبان و لینک دانلود
- دکمه‌های تعاملی برای جابجایی بین نتایج و مشاهده پروژه
- ذخیره نتایج در حافظه برای جلوگیری از درخواست‌های تکراری
- مدیریت خطاها (محدودیت نرخ، نتایج خالی، خطای شبکه)

## 🔧 پیش‌نیازها

- Python 3.9 یا بالاتر
- توکن ربات تلگرام (از [@BotFather](https://t.me/BotFather))
- کلید API اپن‌ایآی (از [OpenAI Platform](https://platform.openai.com/))
- توکن دسترسی گیت‌هاب (از [GitHub Settings](https://github.com/settings/tokens))
